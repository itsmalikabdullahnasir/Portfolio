## 🔧 Customization Quick Reference

### Change Colors
Edit `app/globals.css`:
```css
:root {
  --accent-cyan: #00d9ff;      /* Change this */
  --accent-purple: #9d4edd;    /* Change this */
  --accent-lime: #7fff00;      /* Change this */
}
```

### Add New Section
1. Create `components/sections/NewSection.tsx`
2. Import in `app/page.tsx`
3. Add link to `components/NavBar.tsx`

### Update Projects
Edit `data/projects.ts` and modify the `projects` array.

### Update Skills
Edit `data/skills.ts` and modify the `skillsData` array.

### Add Images
Place images in `public/` and import in components:
```tsx
import Image from 'next/image'
<Image src="/image.png" alt="description" />
```
